Privacy & Security

YOUR BROWSER DESERVES TRANSPARENCY.

💾

Local-first data

History, downloads, permissions and settings live in your own profile folder on your PC — not on our servers. Sync only happens if you create a NEXORA account and turn it on.

🔐

You hold the keys

Your browsing history page is guarded by a password you set. Per-site camera, mic and screen permissions can be allowed or blocked at any time.

🧹

Less tracking surface

Built-in ad & tracker blocking and AI-assisted phishing warnings reduce common web annoyances and traps. No browsing analytics are collected by the browser itself.

🔍

Honest security status

NEXORA is pre-release software. Independent security verification is incomplete, so we make no "unhackable" claims. Found an issue? Report it — contact details will be published with the first release.

Privacy Policy and Security Policy documents will be published alongside the first public release.

FAQ

QUESTIONS, ANSWERED.

Which operating systems will NEXORA support?

The first official installer targets Windows 64-bit. Other platforms have not been announced yet.

Is NEXORA Browser free?

Yes — the browser is planned as a free download, with its source code published on GitHub.

Where do I download it safely?

Only from the official release page linked on this site. Until the first release is published, the download button stays disabled — never trust third-party "NEXORA installers".

Does ESTA AI send my browsing to the cloud?

ESTA runs through the NEXORA backend on your own PC, including an offline on-device chat mode. Cloud model providers are never mandatory — check the release notes for the default configuration.

Do I need API keys or accounts to use the AI?

No. The first launch sets up the free offline AI on your PC automatically — no keys, no sign-ups, no files to edit. A Groq API key is purely optional for cloud chat.

How does the history password work?

Set it in Settings → History Lock. The full history page then asks for that password before showing anything. Turn the lock off and it opens directly.

Can I trust pre-release software with my logins?

Be sensible: NEXORA stores logins with your OS-level browser profile like other Chromium browsers, but independent security review is still pending. Use a password manager and unique passwords everywhere.
