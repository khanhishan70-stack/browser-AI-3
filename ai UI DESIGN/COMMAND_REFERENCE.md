# AI VOICE ASSISTANT - COMMAND REFERENCE

## Quick Command Examples

### System Information
| Command | Response |
|---------|----------|
| "What's the time?" | Current time (HH:MM AM/PM) |
| "What's the date?" | Today's date |

### Calculations
| Command | Response |
|---------|----------|
| "Calculate 5 plus 3" | The answer is 8 |
| "Calculate 10 minus 2" | The answer is 8 |

## Tips & Tricks

1. **Voice Mode**: Toggle voice mode to auto-submit voice commands
2. **Voice Output**: Enable to hear AI responses
3. **Command Mode**: Requires recognized commands
4. **Search Mode**: Ask any question, AI will answer

## Troubleshooting Commands

If something doesn't work:
1. Try speaking clearly and slowly
2. Ensure microphone is enabled
3. Check that backend is running
4. Review the console for error messages
5. Make sure internet connection is active

## Advanced Features

- **Smart Mic Input**: Automatically adjusts to background noise
- **Multi-command Recognition**: Can understand complex commands
- **Browser State Management**: Saves and restores browser windows

- **Custom App Launcher**: Add more apps in backend/app.py
